# Personal Website Documentation

This project is a simple personal website that showcases my work and provides contact information. It consists of three main pages: the home page, a contact page, and a gallery page.

## Project Structure

- **index.html**: The main page of the website that includes a brief bio and links to the contact and gallery pages.
- **pages/contact.html**: A page containing my contact details, including email and phone number.
- **pages/gallery.html**: A gallery page displaying images stored in the `photo` folder.
- **photo**: A folder designated for storing all images used in the gallery page.

## Navigation

- To visit the home page, open `index.html`.
- To view my contact information, click on the "Contact Me" link on the home page or navigate to `pages/contact.html`.
- To see my gallery, click on the "View My Gallery" link on the home page or go to `pages/gallery.html`.

Feel free to explore the website and reach out through the contact page!
